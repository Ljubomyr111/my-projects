## Важливо: що не потрапляє в репозиторій

Див. `.gitignore`. Причини:

1. **Секрети.** `tg-bot/config.json` містить Telegram bot token і DeepSeek API key,
   тому він ігнорується. Для локального запуску створіть його з
   `tg-bot/config.example.json` і впишіть власні ключі.
2. **Важкі файли.** Портативна збірка ComfyUI (~1.9 ГБ), кеш pip (~342 МБ),
   завантажені моделі (~275 МБ) та згенеровані результати лишаються локально —
   GitHub відхиляє файли понад 100 МБ.
3. **Артефакти збірки.** `*.exe`, `*.obj`, `*.stl`, `*.log` тощо.
4. **Вкладений репозиторій.** `homework_p4/git_demo/` — окремий навчальний
   git-репозиторій; його історія лишається локальною, а `main.c` додано як
   звичайний файл.
